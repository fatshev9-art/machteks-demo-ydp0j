    Спасательные прицепы с лебёдкой

    Прицеп с барабанной лебёдкой для эвакуации пострадавшего с опоры. Бензиновый привод, барабан с канатом, ящик для спасательного устройства, заземлений и отводных блоков, двухосное шасси для буксировки. Смотрите тягу, запас каната и комплектацию ящика.
